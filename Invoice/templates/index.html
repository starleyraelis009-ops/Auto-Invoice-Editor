Buat dokumen secara otomatis dari data Excel menggunakan template Anda sendiri.

Mulai membuat dokumen

Upload file Excel yang berisi data dan template Word yang ingin digunakan. Sistem akan membaca data tersebut dan membuat dokumen secara otomatis.

1. Siapkan template Word

Gunakan file Microsoft Word (.docx). Masukkan placeholder pada bagian yang ingin diisi secara otomatis.

DATA SISWA

Nama : {{nama}}

Kelas : {{kelas}}

Nomor Absen : {{no_absen}}

Contoh placeholder

{{nama}} {{nis}} {{nisn}} {{kelas}} {{no_absen}}

2. Siapkan file Excel

Baris pertama Excel digunakan sebagai nama kolom. Baris berikutnya berisi data.

nama kelas no_absen
Budi XI RPL 1 12
Ani XI RPL 1 13

Jumlah kolom tidak harus sama untuk setiap pengguna. Sistem hanya menggunakan data yang dibutuhkan oleh template.
